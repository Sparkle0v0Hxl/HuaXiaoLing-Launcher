## 2. 安装器（`installer/`、`H:\HXL-pack\`）

- payload 从 5MB 占位换成真实主程序：4197 文件 / 402MB。
- **安装 1 秒失败**：Electron 把 `payload\resources\app.asar` 当目录，`copyFile` 报 `EISDIR`。加 `process.noAsar = true`，构建脚本加静态校验，缺这行直接拒绝构建。

- 注册表写了 `--silent` 但代码不识别，已补。
- 构建入口：`H:\HXL-pack\installer-build.js`（支持 `--check` 单跑），`pack.js` 已接入。

## 3. 终末地（`electron/endfield-*.js`、`games-ipc.js`、`main.js`）

### 3.1 启动链路
- `Endfield.exe` 直接启动必被 U8 SDK 拦截（`PC launch auth extraInfo failed 10100`），必须由官方启动器拉起；**不做破解**。
- 方案：点「开始游戏」→ 拉起官方 `Games.exe` → 最小化 → 游戏窗口出现后关闭启动器（**只杀单个 pid，不能用 `taskkill /T`，否则连游戏一起杀**）。
- 官方托管：`readButtonState()` 的 payload 补 `callbackEvent: 'main_btn_state_rsp'`，否则 Qt 端不回包，等 6 秒超时；修后点按钮 1 秒起游戏。
- 提权：只在点「开始游戏」且确实需要时问一次；按钮「开启 / 这次先不用 / 以后不再提醒」；提示杀软需允许并加白名单；三处重复确认框合并。
- 自动熔断：全自动连续失败 3 次 → 降级手动并记录；更新态/用户拒绝/已在运行不计入。
- `getStore is not defined`：`tryOfficialLaunch` 的 `deps` 漏传 `getStore`，已补。
- 多余提醒：同进程只提示一次，文案缩短。

### 3.2 「老是提示新版本」
- 根因：`.vela-game-state.json` 停在 1.6.4，盘上文件已是 1.7.2（官方启动器更新过），版本号不一致就弹。
- 修法：`verifyLocalMatchesRemote()` 按字节复核（根目录重二进制全验、`.blc` 全验、`.chk` 抽样）；对上则修正状态文件并留 `reconciledFrom`，不弹提示；`endfieldVerifyMemo` 进程内只复核一次。
- 踩坑：`main.js` 只解构 `checkEndfieldGame`，漏了 `loadRemoteManifest`，`ReferenceError` 被 catch 吞成 null 静默退回旧逻辑。

### 3.3 「获取资源失败」
- 根因：Persistent 热更层（IFix）与 StreamingAssets 基础包错配（1.6.4 vs 1.7.2），不是网络问题。
- 新增 `electron/game-heat.js`：只改名不删除（`.hxl-heat-<时间>`），热更层早于基础包 10 分钟以上判为遗留；绝不抛异常；未知游戏跳过。接入 7 处（终末地 repair/update/预下载、方舟 repair×2、鸣潮 repair、米哈游 repair）。
- 预下载路径原本直接 return，跳过热更处理（导致「预下载下载了用不了」），已补。

### 3.4 运行时一致性
- 新增 `electron/runtime-check.js`：只查关键文件（`global-metadata.dat`、`globalgamemanagers`、`app.info`、`boot.config`、`config.ini` 等）。
- 配置扩到 7 款（原神/星铁/绝区零/崩坏3/终末地/鸣潮/明日方舟）。
- `auditRuntimesAfterRepair()` 接入全部 6 处 repair。
- 发行版差异（如国服↔国际服 `global-metadata.dat` 差 56 字节）不误报；只报「同一 biz 且明显落后」。
- 硬链接收尾卡顿：`recordPlacedFiles` 改异步，记账 fire-and-forget；`readFileId` 的 `fsutil` 调用不再逐文件，卷序列号加缓存。

## 8. 关键经验（避免重犯）

- 差异基准不能用被镜像过来的清单，否则等于自己跟自己比。
- 硬链接后写渠道文件必须先 `unlink`，否则 `copyFile` 会写穿源客户端。
- 米哈游三款有内建自愈，不要清它们的 `Persistent`（会白重下 12GB 语音包）。
- 复制到非安装目录的蓝原启动器起不来；验证必须改原位置文件 + 用户手动双击。
- 记账类操作不要同步逐文件 `stat`/`spawn`，主进程会卡死。
- 不要为了视觉效果把窗口移到屏幕外；最小化 + 关闭即可。
