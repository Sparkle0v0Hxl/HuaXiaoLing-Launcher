## 二、根因与修法

### 2.1 Setup.exe 是纯 NSIS 向导

- 根因：`H:\花筱灵启动器-源码\installer\package.json` 的 `win.target` 配的是 `"target": "nsis"`，
  外加 `nsis` 段一整套向导配置（oneClick:false / allowToChangeInstallationDirectory:true / installerLanguages zh_CN …）。
  `nsis` target = **向导式安装程序**，会盖掉我们自己的 Electron 界面。
- 交接文档 §6.1 说的「Electron 安装器 + NSIS 外壳」，指的是 electron-builder 的 **`portable` target**
  （portable 本身就是 NSIS 自解压 SFX，解包后跑我们的 exe），**不是 `nsis` target**。这里我一开始理解反了。
- 修法：`installer/package.json` 的 `win.target` 改成 `portable`，删掉整个 `nsis` 段，
  加 `"portable": { "artifactName": "${productName} Setup ${version}.${ext}" }`。
- 实测（05:46–05:51）：
  - 产物 `H:\HXL-pack\dist-installer\HuaXiaoLing-Setup Setup 2.14.0.exe` = **150.89 MB**，
    sha256 `61E705FF8B6D7F5B52D6E9C316ECA39C267FE61DDD77CB0134218D59AB14C43A`
  - 双击 → SFX 解包到 `%TEMP%\<rand>\`（约 407 MB，~40 秒）→ 启动 `HuaXiaoLing-Setup.exe`（PID 12260）
    → **我们自己的窗口出现：736×488，title「花筱灵启动器」**
  - 像素：深色 49.4% / 粉色 9.0% / 纯白 4.7% → 确认是自绘界面，不是 NSIS 向导灰白底
  - 解包结构：`resources\app.asar`（安装器本体 956454 B）+ `resources\payload\{latest.json, resources\{...}}`

### 6.5 结论：卸载器是哪个？

**没有独立卸载器 exe 了。** 卸载入口 = 主程序自己带 `--uninstall` 参数：
`H:\花筱灵启动器\花筱灵启动器.exe --uninstall`

理由（写进 `electron/uninstall.js` 的设计）：复制一份 238 MB 的 Electron 本体当卸载器不现实；
且 Electron 只认执行文件同目录的 `resources\app.asar`，复制出去的 exe 会加载到启动器本体，
反而跑成主界面（这就是最初「卸载里掺进安装」的根因）。
